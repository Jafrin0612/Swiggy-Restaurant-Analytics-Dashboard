# Swiggy Restaurant Analytics Dashboard

## Project Overview
This project is an interactive Power BI dashboard created using a Swiggy restaurant dataset. It provides insights into restaurant performance, food categories, ratings, pricing, delivery time, and city-wise distribution.

## Tools Used
- Power BI
- Power Query
- DAX
- Microsoft Excel

## Dashboard Features
- KPI Cards
- Interactive Slicers
- Bar Chart
- Donut Chart
- Map Visualization
- Restaurant Performance Analysis

## Dataset Columns
- Id
- Area
- City
- Restaurant
- Price
- Average Rating
- Address
- Delivery Time (Min)
- Food Category
- Total Ratings
